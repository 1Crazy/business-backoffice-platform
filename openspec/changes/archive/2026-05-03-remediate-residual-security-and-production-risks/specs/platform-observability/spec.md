## MODIFIED Requirements

### Requirement: 平台输出结构化运行日志
系统 SHALL 输出结构化日志，用于记录请求完成、异常、认证失败、限流、配额拒绝和关键运维事件。日志 MUST 至少包含时间、级别、请求 ID、HTTP method、path、status、duration、错误类型以及可用的用户和租户上下文，且 MUST NOT 记录明文密码、refresh token、API secret 或 cookie 值。生产环境 MUST 支持把结构化日志输出到日志聚合或 APM/可观测平台，并保留本地开发可读输出。

#### Scenario: 受保护接口请求完成
- **WHEN** 已登录用户访问受保护 API 并完成响应
- **THEN** 系统输出结构化访问日志
- **AND** 日志包含请求 ID、租户、用户、路径、状态码和耗时

#### Scenario: 敏感凭证出现在请求中
- **WHEN** 登录、刷新或 Open API 凭证校验请求被记录
- **THEN** 日志不得包含明文密码、refresh token、API secret 或 cookie 值

#### Scenario: 生产环境启用日志聚合
- **WHEN** 后端以生产配置启动
- **THEN** 系统按配置把结构化日志输出到 stdout、文件或日志聚合适配器
- **AND** 日志格式可被运维系统稳定解析

### Requirement: 平台暴露基础健康和指标信号
系统 SHALL 提供可供容器和运维系统使用的健康检查与基础指标信号。健康检查 MUST 能区分进程存活和关键依赖可用性；指标信号 MUST 至少表达进程启动时间、版本信息、请求数量、错误数量和延迟摘要，且暴露策略 MUST 可通过环境变量控制。健康检查 MUST 覆盖数据库、队列/worker、缓存、对象存储或上传存储等当前启用的关键依赖。

#### Scenario: 容器执行健康检查
- **WHEN** 容器健康检查访问健康端点
- **THEN** 系统返回当前进程和关键依赖的健康状态
- **AND** 该端点不要求登录但不得泄露敏感配置

#### Scenario: 运维系统读取指标
- **WHEN** 指标暴露被显式启用
- **THEN** 系统提供基础运行指标
- **AND** 指标内容不包含用户隐私、令牌或业务敏感字段

#### Scenario: 关键依赖不可用
- **WHEN** 数据库、队列、缓存或启用的上传存储不可用
- **THEN** 健康接口返回 degraded 或 unhealthy 状态
- **AND** 响应只暴露依赖类别和状态，不暴露凭证或内部连接串

## ADDED Requirements

### Requirement: 平台执行分层 API 限流
系统 SHALL 对浏览器后台 API、认证 API、Open API、高成本查询和上传入口执行分层限流。限流 MUST 支持按租户、用户、来源 IP、凭证和接口类别组合计数；生产或多实例部署 MUST 使用共享状态；限流拒绝 MUST 返回可识别错误并记录结构化安全事件。

#### Scenario: 普通业务列表被高频访问
- **WHEN** 同一用户、租户或来源在短时间内高频请求客户、线索或机会列表
- **THEN** 系统按普通业务 API 阈值限制请求
- **AND** 不影响其他租户的正常访问

#### Scenario: 高成本导出或上传被高频触发
- **WHEN** 同一用户或租户连续触发导出、上传或批任务创建并超过阈值
- **THEN** 系统拒绝后续请求并返回限流错误
- **AND** 系统记录限流事件和请求 ID

#### Scenario: 多实例下触发限流
- **WHEN** 同一风险主体的请求分散命中多个 API 实例
- **THEN** 系统使用共享限流状态累计请求
- **AND** 达到阈值后所有实例一致拒绝
