## ADDED Requirements

### Requirement: 系统管理支持租户配置与开放平台治理
系统 SHALL 提供租户级系统管理能力，用于治理租户配置、开放 API、Webhook、身份连接器和关键基础设施状态。租户管理员 MUST 只能管理本租户相关配置。

#### Scenario: 租户管理员管理开放平台配置
- **WHEN** 租户管理员进入系统管理中的开放平台入口
- **THEN** 系统允许其管理本租户的 API 凭证、Webhook 和身份连接器配置

#### Scenario: 租户管理员查看本租户基础设施状态
- **WHEN** 租户管理员查看系统管理摘要
- **THEN** 系统仅展示本租户相关的存储、任务、通知和集成状态，而不会暴露平台级其他租户信息

### Requirement: 平台级审计可以追踪租户配置与集成变更
系统 SHALL 为租户配置、开放平台接入和平台运营动作提供平台级审计能力，使平台运营者能够追踪“谁在何时对哪个租户做了什么变更”。

#### Scenario: 平台记录租户配置变更
- **WHEN** 租户管理员或平台运营者修改租户关键配置
- **THEN** 系统记录该变更的租户归属、操作者、动作类型和时间

#### Scenario: 平台记录集成接入失败
- **WHEN** 租户的 API、Webhook 或身份接入发生关键失败
- **THEN** 系统保存对应的审计或运行记录，供平台或租户管理员追踪排查
