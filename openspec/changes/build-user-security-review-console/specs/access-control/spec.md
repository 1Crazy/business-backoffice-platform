## ADDED Requirements

### Requirement: 管理员可以在平台治理域审核安全锁定账号
系统 SHALL 在平台治理域提供账号安全审核工作台，让具备授权的管理员查看 `REVIEW_REQUIRED` 和 `LOCKED` 的账号，并执行解除锁定操作。工作台 MUST 展示锁定状态、锁定原因、锁定时间和最近审核时间。

#### Scenario: 管理员查看待审核账号
- **WHEN** 具备用户读取权限的管理员进入平台治理域中的账号安全审核工作台
- **THEN** 系统展示所有 `REVIEW_REQUIRED` 和 `LOCKED` 的账号
- **AND** 列表中包含用户名、显示名称、角色、锁定状态、锁定原因、锁定时间和最近审核时间

#### Scenario: 管理员解除账号锁定
- **WHEN** 具备 `user:write` 权限的管理员在账号安全审核工作台中对某个被锁定账号执行解除锁定
- **THEN** 系统调用统一解锁动作恢复该账号
- **AND** 列表刷新后该账号不再出现在安全审核工作台中

#### Scenario: 无写权限管理员只能查看不能操作
- **WHEN** 管理员具备用户读取权限但不具备 `user:write`
- **THEN** 系统允许其查看安全锁定账号
- **AND** 不允许其执行解除锁定操作
